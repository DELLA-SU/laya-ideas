개인정보처리방침

HENA 열 가지(아이디어 뽑기)는 키워드에 관련된 이미지와 읽을거리를 찾아 개인 아카이브, 무드보드와 브레인스토밍에 활용하는 도구입니다. 시행일: 2026년 10월 5일.

브라우저에 저장되는 자료

저장한 레퍼런스, 검색별 확인 기록, 무드보드 위치·메모·연결선은 사용하는 브라우저의 localStorage에 저장됩니다. 현재 별도 회원가입이나 서버에 저장하는 사용자 계정 기능은 없습니다. 브라우저 사이트 데이터를 삭제하면 이 기록도 삭제됩니다. 공개 사이트와 localhost의 저장 공간은 서로 다르며 자동 이전되지 않습니다.

검색과 외부 서비스

검색어는 관련 결과를 요청하기 위해 연결된 검색·자료 API로 전송됩니다. 공개 GitHub Pages 버전은 Wikimedia Commons, Wikidata, 위키백과, Art Institute of Chicago, Crossref에 자료를 요청하고, MyMemory에 검색어 또는 논문 제목·짧은 발췌의 번역을 요청합니다. 각 서비스와 이미지 원본 호스트는 요청 시 IP 주소, 브라우저 정보 등 일반 접속 정보를 받을 수 있습니다. 검색어와 메모에는 비밀번호 등 민감한 정보를 입력하지 마세요.

Pinterest 연결

현재 Pinterest 공식 API 인증은 신청 중이며 이 공개 버전에 토큰은 포함되지 않습니다. 원본 검색 링크를 열면 Pinterest 웹사이트로 이동합니다. 인증 기능이 제공되는 경우 승인 화면에서 요청 권한을 확인할 수 있으며, 비밀 토큰을 공개 웹페이지나 저장소에 넣지 않습니다. 인증 방식과 처리 범위가 바뀌면 이 방침도 갱신합니다.

호스팅과 원본 자료

이 사이트는 GitHub Pages에 호스팅됩니다. GitHub는 서비스 운영 및 보안을 위한 접속 정보를 처리할 수 있습니다. 외부 서비스의 처리에는 해당 서비스의 정책이 적용됩니다. 자료의 저작권과 이용 조건은 각 카드의 원본 링크에서 확인할 수 있습니다.
